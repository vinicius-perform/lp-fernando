# Landing Page — Dr. Fernando Silveira

Landing page institucional de alta conversão para o Dr. Fernando Silveira, com foco em Cirurgia Facial e Blefaroplastia (Rejuvenescimento do Olhar).

## 🚀 Tecnologias

- **HTML5 & CSS3 Vanilla:** Design responsivo, tipografia editorial e container centralizado de alta definição.
- **JavaScript Moderno:** Carousel de depoimentos, acordeão FAQ fluido, e modal interativo com player nativo de vídeo (HTML5).
- **Node.js Local Server (`server.js`):** Servidor HTTP integrado com suporte a streaming de vídeo parcial (HTTP 206 Range Requests).

## 📁 Estrutura de Arquivos

```text
lp-fernando/
├── index.html        # Página principal da landing page
├── server.js         # Servidor local Node.js com suporte a streaming de vídeo
├── assets/           # Imagens, capas, fotos e vídeos de relatos
├── public/           # Ativos e fotografias editoriais em alta definição
└── .gitignore
```

## 💻 Como Rodar Localmente

1. Execute o servidor local:
   ```bash
   node server.js
   ```
2. Abra seu navegador em:
   ```text
   http://localhost:5500
   ```
